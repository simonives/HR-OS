# hr-os MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `hr-os` workforce-planning MVP — a gated, auditable orchestrator that walks a single HR workflow (workforce planning before hiring) through five explicit process gates, calling Claude to do the work inside each gate and refusing to advance until each gate's exit condition is met.

**Architecture:** A hand-rolled TypeScript state machine (`WorkflowRunner`) walks an ordered list of `StageDefinition`s. Each stage builds a prompt (grounded in `src/resources/`), calls a swappable `ModelClient`, verifies the response against a Zod schema, and appends one row to an append-only SQLite audit log. Workflow state is never held in memory across process invocations — it is reconstructed from the audit log on every call, so the CLI (and later an API) can be stateless per invocation. A `CapabilityRegistry` resolves a stage's capability requests in order: native model tools, then a declared external-capability registry (MCP servers / platform connectors), then "none" (resource-library-only fallback).

**Tech Stack:** TypeScript (strict, ESM, NodeNext), `@anthropic-ai/sdk`, `zod`, `node:sqlite` (built into Node 22+, no native dependency), `vitest` for tests, `node:util.parseArgs` for the CLI (no CLI framework dependency).

**Spec:** `docs/superpowers/specs/2026-08-17-hr-os-design.md`

## Global Constraints

- Provider scope for MVP: Anthropic only. The `ModelClient` interface must not leak Anthropic-specific types so `OpenAIClient`/`DeepSeekClient` can be added later without touching `WorkflowRunner` or gate code.
- Engine pattern: a fixed-sequence, hand-rolled state machine. The model never chooses or reorders stages.
- Audit trail is append-only SQLite, one row per gate transition, columns: case ID, workflow name, stage name, gate type, approval type, decision, approver, artifact JSON, resource paths used, capabilities requested, capabilities resolved, model, prompt version, timestamp. This is governance-grade from the MVP — do not defer or simplify this table.
- `approvalType` is `"auto-verified"` (orchestrator checks the artifact programmatically) or `"human-approval"` (orchestrator halts and waits for an explicit approve/reject).
- Capability resolution order for every stage: native model tools first, then the declared external capability registry, then `"none"`. The MVP ships with an empty external registry (`hr-os.config.json` with `{"externalCapabilities": {}}`) but the resolution logic and human-approval-on-use posture must be fully implemented and tested — only the populated entries are out of scope.
- Resource grounding is plain file reads under `src/resources/` addressed by relative path — no vector DB, no search index.
- Remove the `@modelcontextprotocol/sdk` dependency — this project is no longer an MCP server.
- Interface: core orchestrator logic is a library; the CLI is a thin client over the same functions an HTTP API would call later. No workflow logic may live inside `src/cli/index.ts` beyond argument parsing and dispatch.
- TypeScript strict mode (existing `tsconfig.json` — do not relax it).
- No placeholders, no `TODO`s, no speculative code for gate types or domains beyond what workforce-planning uses.

import { readFileSync, existsSync } from "node:fs";
import type { CapabilityResolution, ModelClient } from "../types.js";

export interface CapabilityRegistryConfig {
  externalCapabilities: Record<string, string>;
}

export class CapabilityRegistry {
  private readonly externalCapabilities: Record<string, string>;

  constructor(config: CapabilityRegistryConfig) {
    this.externalCapabilities = config.externalCapabilities;
  }

  static loadFromFile(path: string): CapabilityRegistry {
    if (!existsSync(path)) {
      return new CapabilityRegistry({ externalCapabilities: {} });
    }
    const raw = readFileSync(path, "utf-8");
    const parsed = JSON.parse(raw) as CapabilityRegistryConfig;
    return new CapabilityRegistry(parsed);
  }

  resolve(capability: string, client: ModelClient): CapabilityResolution {
    if (client.nativeCapabilities.includes(capability)) {
      return { capability, source: "native", ref: client.providerName };
    }
    const externalRef = this.externalCapabilities[capability];
    if (externalRef) {
      return { capability, source: "external", ref: externalRef };
    }
    return { capability, source: "none" };
  }
}
```

import type Anthropic from "@anthropic-ai/sdk";
import type { Message, ModelClient, ModelResponse } from "../types.js";

const DEFAULT_MODEL = process.env.HR_OS_ANTHROPIC_MODEL ?? "claude-sonnet-4-5";
const NATIVE_CAPABILITIES = ["web-search"] as const;

export class AnthropicClient implements ModelClient {
  readonly providerName = "anthropic";
  readonly nativeCapabilities: readonly string[] = NATIVE_CAPABILITIES;

  constructor(
    private readonly sdk: Pick<Anthropic, "messages">,
    private readonly model: string = DEFAULT_MODEL
  ) {}

  async complete(messages: Message[]): Promise<ModelResponse> {
    const response = await this.sdk.messages.create({
      model: this.model,
      max_tokens: 4096,
      messages: messages.map((m) => ({ role: m.role, content: m.content })),
    });
    const block = response.content.find((c) => c.type === "text");
    if (!block || block.type !== "text") {
      throw new Error("Anthropic response contained no text block");
    }
    return { text: block.text };
  }
}
```

Note: `DEFAULT_MODEL` is read from `HR_OS_ANTHROPIC_MODEL` with a fallback — resolve the current Claude model ID via `/model` or the Anthropic docs at deployment time rather than trusting the literal string above, which will go stale.

```typescript
import { readFileSync, existsSync, readdirSync, statSync } from "node:fs";
import { join } from "node:path";

export function loadResourceContent(baseDir: string, relativePaths: string[]): string {
  const sections: string[] = [];
  for (const relativePath of relativePaths) {
    const fullPath = join(baseDir, relativePath);
    if (!existsSync(fullPath)) {
      continue;
    }
    const stat = statSync(fullPath);
    if (stat.isDirectory()) {
      for (const entry of readdirSync(fullPath)) {
        if (entry.endsWith(".md")) {
          sections.push(readFileSync(join(fullPath, entry), "utf-8"));
        }
      }
    } else {
      sections.push(readFileSync(fullPath, "utf-8"));
    }
  }
  return sections.join("\n\n---\n\n");
}
```

import type { ApprovalType } from "../types.js";

export interface GateTransitionRecord {
  caseId: string;
  workflowName: string;
  stageName: string;
  gateType: string | null;
  approvalType: ApprovalType;
  decision: "advance" | "reject" | "awaiting-approval";
  approver: string;
  artifactJson: string;
  resourcePathsUsed: string;
  capabilitiesRequested: string;
  capabilitiesResolved: string;
  model: string;
  promptVersion: string;
}

interface GateTransitionRow {
  case_id: string;
  workflow_name: string;
  stage_name: string;
  gate_type: string | null;
  approval_type: ApprovalType;
  decision: "advance" | "reject" | "awaiting-approval";
  approver: string;
  artifact_json: string;
  resource_paths_used: string;
  capabilities_requested: string;
  capabilities_resolved: string;
  model: string;
  prompt_version: string;
}

export class AuditLog {
  private readonly db: DatabaseSync;

  constructor(dbPath: string) {
    this.db = new DatabaseSync(dbPath);
    this.db.exec(`
      CREATE TABLE IF NOT EXISTS gate_transitions (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        case_id TEXT NOT NULL,
        workflow_name TEXT NOT NULL,
        stage_name TEXT NOT NULL,
        gate_type TEXT,
        approval_type TEXT NOT NULL,
        decision TEXT NOT NULL,
        approver TEXT NOT NULL,
        artifact_json TEXT NOT NULL,
        resource_paths_used TEXT NOT NULL,
        capabilities_requested TEXT NOT NULL,
        capabilities_resolved TEXT NOT NULL,
        model TEXT NOT NULL,
        prompt_version TEXT NOT NULL,
        created_at TEXT NOT NULL DEFAULT (datetime('now'))
      )
    `);
  }

  append(record: GateTransitionRecord): void {
    const stmt = this.db.prepare(`
      INSERT INTO gate_transitions
        (case_id, workflow_name, stage_name, gate_type, approval_type, decision, approver,
         artifact_json, resource_paths_used, capabilities_requested, capabilities_resolved,
         model, prompt_version)
      VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
    `);
    stmt.run(
      record.caseId,

import { z } from "zod";
import type { GateType, VerifyResult } from "../types.js";

const problemFramingSchema = z.object({
  problem: z.string().min(1),
  stakeholders: z.array(z.string()).min(1),
  constraints: z.array(z.string()),
});

const successCriteriaFirstSchema = z.object({
  successCriteria: z.array(z.string()).min(1),
  decision: z.string().min(1),
});

const calibrationAndConsultationSchema = z.object({
  reviewer: z.string().min(1),
  recommendation: z.string().min(1),
  consultationNotes: z.string(),
});

const outcomeVerificationSchema = z.object({
  outcomeMatchesDecision: z.boolean(),
  evidence: z.string().min(1),
});

const schemasByGateType: Record<GateType, z.ZodTypeAny> = {
  "problem-framing": problemFramingSchema,
  "success-criteria-first": successCriteriaFirstSchema,
  "calibration-and-consultation": calibrationAndConsultationSchema,
  "outcome-verification": outcomeVerificationSchema,
};

export function verifyGateArtifact(gateType: GateType, artifactText: string): VerifyResult {
  let parsed: unknown;
  try {
    parsed = JSON.parse(artifactText);
  } catch {
    return { ok: false, reason: "artifact is not valid JSON" };
  }

  const schema = schemasByGateType[gateType];
  const result = schema.safeParse(parsed);
  if (!result.success) {
    return { ok: false, reason: result.error.issues.map((i) => i.message).join("; ") };
  }

  if (gateType === "outcome-verification") {
    const data = parsed as z.infer<typeof outcomeVerificationSchema>;
    if (!data.outcomeMatchesDecision) {
      return { ok: false, reason: `outcome does not match decision: ${data.evidence}` };
    }
  }

  return { ok: true };
}

```typescript
import type {
  CapabilityResolution,
  ModelClient,
  StageContext,
  StageDefinition,
  WorkflowDefinition,
} from "../types.js";
import { CapabilityRegistry } from "../capabilities/registry.js";
import { AuditLog, type GateTransitionRecord } from "../audit/audit-log.js";
import { loadResourceContent } from "../resources/grounding.js";

const PROMPT_VERSION = "1";

export interface RunResult {
  status: "advanced" | "awaiting-approval" | "rejected" | "complete";
  stageName: string;
  artifact?: unknown;
  reason?: string;
}

export class WorkflowRunner {
  constructor(
    private readonly workflow: WorkflowDefinition,
    private readonly modelClient: ModelClient,
    private readonly capabilityRegistry: CapabilityRegistry,
    private readonly auditLog: AuditLog,
    private readonly resourcesBaseDir: string
  ) {}

  async start(caseId: string): Promise<RunResult> {
    const history = this.loadHistory(caseId);
    if (history.length > 0) {
      throw new Error(`case ${caseId} already started`);
    }
    return this.advance(caseId);
  }

  async approve(caseId: string, approver: string, decision: "approve" | "reject"): Promise<RunResult> {
    const history = this.loadHistory(caseId);
    const last = history[history.length - 1];
    if (!last || last.decision !== "awaiting-approval") {
      throw new Error(`case ${caseId} has no stage awaiting approval`);
    }
    const stage = this.workflow.stages.find((s) => s.name === last.stageName);
    if (!stage) {
      throw new Error(`unknown stage ${last.stageName}`);
    }
    if (decision === "reject") {
      this.auditLog.append({ ...last, decision: "reject", approver });
      return { status: "rejected", stageName: stage.name };
    }
    this.auditLog.append({ ...last, decision: "advance", approver });
    return this.advance(caseId);
  }

  status(caseId: string): RunResult {
    const history = this.loadHistory(caseId);
    const last = history[history.length - 1];
    if (!last) {
      throw new Error(`case ${caseId} not found`);
    }
    if (last.decision === "awaiting-approval") {
      return { status: "awaiting-approval", stageName: last.stageName, artifact: JSON.parse(last.artifactJson) };
    }
    const stageIndex = this.nextStageIndex(history);
    if (stageIndex === -1) {
      return { status: "complete", stageName: last.stageName };
    }
    return { status: "advanced", stageName: last.stageName };
  }

  private loadHistory(caseId: string): GateTransitionRecord[] {
    return this.auditLog.getCaseHistory(caseId).filter((r) => r.workflowName === this.workflow.name);
  }

  private priorArtifacts(history: GateTransitionRecord[]): Record<string, unknown> {
    const artifacts: Record<string, unknown> = {};
    for (const record of history) {
      if (record.decision === "advance") {
        artifacts[record.stageName] = JSON.parse(record.artifactJson);
      }
    }
    return artifacts;
  }

  private nextStageIndex(history: GateTransitionRecord[]): number {
    const advancedStageNames = new Set(history.filter((r) => r.decision === "advance").map((r) => r.stageName));
    return this.workflow.stages.findIndex((s) => !advancedStageNames.has(s.name));
  }

  private resolveCapabilities(stage: StageDefinition): CapabilityResolution[] {
    return stage.requestedCapabilities.map((c) => this.capabilityRegistry.resolve(c, this.modelClient));
  }

  private async runStage(
    caseId: string,
    stage: StageDefinition,
    priorArtifacts: Record<string, unknown>
  ): Promise<RunResult> {
    const groundingText = loadResourceContent(this.resourcesBaseDir, stage.resourcePaths);
    const capabilityResolutions = this.resolveCapabilities(stage);
    const context: StageContext = {
      caseId,
      workflowName: this.workflow.name,
      priorArtifacts,
      groundingText,
      capabilityResolutions,
    };
    const messages = stage.buildPrompt(context);
    const response = await this.modelClient.complete(messages);
    const verifyResult = stage.verify(response.text);

    const baseRecord: GateTransitionRecord = {
      caseId,
      workflowName: this.workflow.name,
      stageName: stage.name,
      gateType: stage.gateType,
      approvalType: stage.approvalType,
      decision: "reject",
      approver: "system",
      artifactJson: response.text,
      resourcePathsUsed: JSON.stringify(stage.resourcePaths),
      capabilitiesRequested: JSON.stringify(stage.requestedCapabilities),
      capabilitiesResolved: JSON.stringify(capabilityResolutions),
      model: this.modelClient.providerName,
      promptVersion: PROMPT_VERSION,
    };

    if (!verifyResult.ok) {
      this.auditLog.append(baseRecord);
      return { status: "rejected", stageName: stage.name, reason: verifyResult.reason };
    }

    if (stage.approvalType === "human-approval") {
      this.auditLog.append({ ...baseRecord, decision: "awaiting-approval" });
      return { status: "awaiting-approval", stageName: stage.name, artifact: JSON.parse(response.text) };
    }

    this.auditLog.append({ ...baseRecord, decision: "advance" });
    return { status: "advanced", stageName: stage.name, artifact: JSON.parse(response.text) };
  }

  private async advance(caseId: string): Promise<RunResult> {
    let history = this.loadHistory(caseId);
    let stageIndex = this.nextStageIndex(history);

    while (stageIndex !== -1) {
      const stage = this.workflow.stages[stageIndex];
      if (!stage) {
        throw new Error(`stage index ${stageIndex} out of range`);
      }
      const priorArtifacts = this.priorArtifacts(history);
      const result = await this.runStage(caseId, stage, priorArtifacts);
      if (result.status !== "advanced") {
        return result;
      }
      history = this.loadHistory(caseId);
      stageIndex = this.nextStageIndex(history);
    }

    const lastStage = this.workflow.stages[this.workflow.stages.length - 1];
    return { status: "complete", stageName: lastStage ? lastStage.name : "" };
  }
}

#!/usr/bin/env node
import { parseArgs } from "node:util";
import { randomUUID } from "node:crypto";
import { join } from "node:path";
import Anthropic from "@anthropic-ai/sdk";
import { WorkflowRunner, type RunResult } from "../orchestrator/workflow-runner.js";
import { workforcePlanningWorkflow } from "../domains/workforce-planning/workflow.js";
import { AnthropicClient } from "../providers/anthropic-client.js";
import { CapabilityRegistry } from "../capabilities/registry.js";
import { AuditLog } from "../audit/audit-log.js";

export interface CliRunner {
  start(caseId: string): Promise<RunResult>;
  status(caseId: string): RunResult;
  approve(caseId: string, approver: string, decision: "approve" | "reject"): Promise<RunResult>;
}

export async function dispatch(argv: string[], runner: CliRunner): Promise<unknown> {
  const [command, ...rest] = argv;

  if (command === "plan-workforce" && rest[0] === "start") {
    const caseId = randomUUID();
    const result = await runner.start(caseId);
    return { caseId, ...result };
  }

  if (command === "status") {
    const caseId = rest[0];
    if (!caseId) {
      throw new Error("usage: hr-os status <caseId>");
    }
    return runner.status(caseId);
  }

  if (command === "approve") {
    const caseId = rest[0];
    if (!caseId) {
      throw new Error("usage: hr-os approve <caseId> [--reject]");
    }
    const { values } = parseArgs({ args: rest.slice(1), options: { reject: { type: "boolean" } } });
    return runner.approve(caseId, process.env.USER ?? "unknown", values.reject ? "reject" : "approve");
  }

  throw new Error(`unknown command: ${command}`);
}

function buildRunner(): WorkflowRunner {
  const apiKey = process.env.ANTHROPIC_API_KEY;
  if (!apiKey) {
    throw new Error("ANTHROPIC_API_KEY is not set");
  }
  const sdk = new Anthropic({ apiKey });
  const modelClient = new AnthropicClient(sdk);
  const registry = CapabilityRegistry.loadFromFile(join(process.cwd(), "hr-os.config.json"));
  const auditLog = new AuditLog(join(process.cwd(), "hr-os-audit.db"));
  const resourcesBaseDir = join(process.cwd(), "src", "resources");
  return new WorkflowRunner(workforcePlanningWorkflow, modelClient, registry, auditLog, resourcesBaseDir);
}

export async function runCli(argv: string[]): Promise<void> {
  const runner = buildRunner();
  const result = await dispatch(argv, runner);
  console.log(JSON.stringify(result, null, 2));
}

if (import.meta.url === `file://${process.argv[1]}`) {
  runCli(process.argv.slice(2)).catch((err: unknown) => {
    console.error(err instanceof Error ? err.message : String(err));
    process.exitCode = 1;
  });
}
```

# hr-os

A gated AI orchestrator for enterprise HR practice. Modelled philosophically on [Superpowers](https://github.com/obra/superpowers) — the same gate discipline Superpowers applies to a software dev/CI-CD lifecycle, applied instead to how a mature HR function actually operates: workforce planning before hiring, structured investigation before disciplinary action, evidence-based design before policy, proper consultation before organisational change.

> **Status:** MVP — one gated workflow (workforce planning), Anthropic only. See `docs/superpowers/specs/2026-08-17-hr-os-design.md` for the full design and `docs/superpowers/plans/2026-08-17-hr-os-mvp.md` for how it was built.

## Why not MCP

hr-os is not an MCP server. It is its own orchestrator: an application that calls whichever model API is configured (Anthropic for the MVP; OpenAI and DeepSeek adapters slot into the same `ModelClient` interface later). Gate discipline is enforced in code by a fixed-sequence state machine — the model does the work inside a stage, but never chooses whether to skip one.

## The five gates

| Gate | What it gates |
| :--- | :--- |
| `problem-framing` | An intervention starts from an explicit problem statement, not a jump to a solution. |
| `structured-investigation` | Adverse action on a person requires root-cause fact-finding first. (Not yet used by any MVP workflow.) |
| `success-criteria-first` | A design's success criteria are agreed before the design work. |
| `calibration-and-consultation` | A decision is reviewed by the right second party before it lands. |
| `outcome-verification` | A case only closes once the outcome is shown to match what was decided. |

## MVP: workforce planning before hiring

```
demand-signal-capture (problem-framing, auto-verified)
  -> workforce-plan-gate (success-criteria-first, human-approval)
  -> role-design-and-levelling (auto-verified)
  -> budget-approval-gate (calibration-and-consultation, human-approval)
  -> requisition-released (outcome-verification, auto-verified)
```

Every gate transition is logged to an append-only SQLite audit trail (`hr-os-audit.db`), governance-grade from the MVP: who approved what, when, against which evidence, using which model and prompt version.
